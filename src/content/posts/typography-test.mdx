## Code Blocks and Inline Formatting

### Inline Elements

Markdown supports common inline decorations without raw HTML:

- Use inline code for terms like `const x = 42`, `minmax(0, 1fr)`, and `--ny-color-bg`.
- Use **bold text** for strong emphasis.
- Use _italic text_ for secondary emphasis.
- Use ~~strikethrough text~~ for removed or rejected ideas.
- Use regular text when the format is not supported by Markdown instead of forcing HTML into the document.

Keyboard combinations can be written as inline code: press `Ctrl` + `Shift` + `R` for a hard refresh, or tap `Esc` to dismiss drawer widgets.

### Definition-Style Content

Markdown does not have a native description-list syntax, so use a simple list instead.

- **CSS Custom Properties**: Variables defined by CSS authors and reused throughout a document, such as `--ny-color-bg`.
- **JIT Compilation**: Just-in-time compilation improves bytecode execution by compiling hot paths into native machine code at runtime.

### Syntax Highlighting Mockup

```rust
// Simple Rust function demonstrating code formatting
fn calculate_fibonacci(n: u32) -> u64 {
    let mut a = 0;
    let mut b = 1;

    for _ in 0..n {
        let temp = a + b;
        a = b;
        b = temp;
    }

    a
}

fn main() {
    let result = calculate_fibonacci(10);
    println!("Fibonacci(10) is {}", result);
}
```

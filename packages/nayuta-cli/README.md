# Nayuta CLI

A standalone TypeScript package for creating and managing Nayuta blogs with Bun.
The `nayuta` command offers CLI and terminal UI modes in English, Simplified
Chinese, Traditional Chinese (Taiwan), and Traditional Chinese (Hong Kong).

From the theme checkout, run `bun run cli --help`. Package development uses
`bun run check`, `bun run test`, and `bun run build` in this directory.
